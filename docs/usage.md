# Usage Guide

OpenBench AI can be used either from the **Command-Line Interface (`openbench`)** or programmatically via its **Python API**.

---

## 1. Command-Line Interface (CLI)

### Validate a Dataset (`validate-dataset`)

Validates a single `.jsonl` file or recursively validates all `.jsonl` files inside a directory:

```bash
openbench validate-dataset datasets/reasoning/sample.jsonl
openbench validate-dataset datasets/
```

If a record is malformed or has a duplicate ID, `openbench` prints the exact file path and line number to `stderr` and exits with code `1`.

### Evaluate Model Responses (`evaluate`)

Evaluates a JSON response file against a JSONL dataset:

```bash
openbench evaluate \
  --dataset datasets/reasoning/sample.jsonl \
  --responses examples/sample_responses.json \
  --metrics exact_match accuracy keyword_coverage \
  --output results/
```

- `--dataset`: Path to a `.jsonl` file or dataset directory.
- `--responses`: Path to a `.json` file containing one or more model response sets.
- `--metrics`: One or more metric names (`exact_match`, `accuracy`, `keyword_coverage`).
- `--output`: Directory path (writes `<model_slug>.json` and `<model_slug>.md`) or a specific `.json`/`.md` file path.

### Compare Multiple Models (`compare`)

Compares two or more JSON evaluation reports generated by `openbench evaluate`:

```bash
openbench compare \
  --results results/model_a.json \
  --results results/model_b.json \
  --output results/comparison.md
```

## 2. Python API Usage

### Basic Single-Model Evaluation

```python
from openbench.dataset import DatasetLoader
from openbench.evaluator import EvaluationConfig, Evaluator, ResponseLoader
from openbench.reporting import ReportGenerator

dataset = DatasetLoader.load("datasets/reasoning/sample.jsonl")
responses = ResponseLoader.load_file("examples/sample_responses.json")

config = EvaluationConfig(metric_names=["exact_match", "accuracy", "keyword_coverage"])
evaluator = Evaluator(config=config)
result = evaluator.evaluate(dataset, responses)

ReportGenerator.save_json(result, "results/alphabaseline.json")
ReportGenerator.save_markdown(result, "results/alphabaseline.md")
```

### Customizing Text Normalization

```python
from openbench.evaluator import EvaluationConfig, Evaluator
from openbench.metrics.normalization import NormalizationConfig

norm_config = NormalizationConfig(
    strip_whitespace=True,
    case_sensitive=True,       # Enforce strict uppercase/lowercase matching
    collapse_whitespace=True,
    strip_punctuation=False,
)
evaluator = Evaluator(config=EvaluationConfig(normalization=norm_config))
```
